# Eleventy Tutorial

This is an introduction to Eleventy using GitHub Codespaces

We will learn later how to create pages, style them, etc.

Markdown:

# This is a huge headline.
###### This is the smallest headline.
This is a paragraph of content.
This is a [link]([title](https://www.example.com)) to another website.
This is a picture ![alt text](image.jpg).
1. This is an ordered list. (including this line and the next 2 lines)
2. *This line is bolded.**
3. *This line is italicized.*
- This is an unordered list. (including this line and the next line)
- ~~This line is struck through.~~

HTML:

<h1>This is a huge headline.</h1>
<h6>This is the smallest headline.</h6>
<p>This is a paragraph of content.</p>
This is a <a href="">link</a> to another website.
This is a picture <img src="" alt"">.
<ol>This is an ordered list. (including this line and the next 2 lines)
<li><strong>This line is bolded.</strong></li>
<li><em>This line is italicized.</em></li></ol>
<ul>This is an unordered list. (including this line and the next line)
<li><s>This line is struck through.</s></li>
</ul>
